# The logo of Koji

A wooden box (masu) of rice: koji is grown on rice.

| File | What it is |
| --- | --- |
| `koji-logo.svg` | The logo, in color, on a transparent background. |
| `koji-icon.svg` | The logo on its yellow square, rounded: icons, the favicon of the site, the icon of the extension of VS Code. |
| `koji-avatar.svg`, `koji-avatar.png` | The logo on the yellow square whole, for avatars (the sites round them). |
| `koji-logo-mono.svg` | In one color (`currentColor`): black, white or any other. |

Colors: yellow `#ffd372`, rice `#ffffff`, top of the box `#f5ecd8`, left side `#d9d5c8`, right side
`#e7ddc7`.
