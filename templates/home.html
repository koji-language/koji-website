Koji
{{header}}

Simple, readable and fast.

Koji is a statically typed language, compiled to machine code by a compiler written in Koji. Errors are values, numbers are exact, and the code says what it does.

{{content}}

Errors are values

No exceptions and no null: a function that can fail returns a Result, and ? passes the error on. match checks that every case is handled.

Exact numbers

A number with a point is a decimal, so 0.1 + 0.2 is 0.3. Integers do not overflow silently, and float is there when you want the hardware's.

Values, not references

Assigning a list gives a copy, made only when one of them changes. Files and sockets are closed when their owner goes away: no garbage collector, no defer.

Tasks without async

Tasks run ordinary code, in groups that wait for them, with channels and shared values. No call blocks the others, and a task that computes is preempted.

A compiler of its own

kojic writes machine code for x86-64 and arm64 and links it with its own linker. Building Koji needs nothing but gzip: no C compiler, no LLVM.

A useful standard library

HTTP with TLS 1.3 written in Koji, JSON, regular expressions, files, processes, dates, a command line parser, and kojic test for tests next to the code.

Try it

Download the package of your platform, unpack it and run a program:

tar -xzf koji-{{version}}-linux-x64.tar.gz
export PATH=$PWD/koji-{{version}}-linux-x64:$PATH
kojic run hello.kj

Packages for Linux, macOS and Windows are on the download page; the documentation covers the language and its standard library. For Visual Studio Code, install the extension Koji.
